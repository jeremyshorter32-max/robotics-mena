# Robotics MENA — Articulated Arm + Frame / Brand master

This package develops the approved Option 1A logo into a bilingual working identity system.

## Contents
- `symbol_*.svg/png`: main marks, light / dark / mono
- `logo_{en,ar,bilingual}_{horizontal,stacked}_{light,dark}.svg/png`: full signature combinations
- `favicon_{light,dark}_{16,24,32,48,64}.png`: optical micro-mark, simplified for small sizes
- `favicon.ico`: multi-size browser favicon
- `app_icon_*.svg/png`: social/app icon variants
- `logo_construction.svg/png`: editable construction/rationale sheet
- `og_{en,ar}_{light,dark}_1200x630.svg/png`: social share templates
- `newsletter_header_{light,dark}_1200x320.svg/png`: newsletter templates
- `social_banner_1500x500.svg/png`: social / header canvas
- `pattern_engineered.svg/png`: restrained identity pattern
- `brand_tokens.css`: light/dark + RTL design tokens
- `brand_guide.html`: visual identity guidelines, view in any browser

## Core values
Violet: #5B3DF5; violet dark mode: #8B74FF; ink #12121A; bg #F2F3F7; dark #0B0B12; data teal #007A96; dark cyan #3CCBE6.

## Typography
Readex Pro (English and Arabic); IBM Plex Mono (data and Latin labels). SVGs contain editable text and fallback font references. For public deployment load the named families, verify Arabic shaping and outline final logo text for guaranteed reproduction. No font files are distributed in this package.

## Design logic
Octagonal open frame = regional record; mechanical arm with joints and gripper = real physical robotics; small violet point = verified deployment. The design is not intended to imply certification or official governmental status.

## Important
These are production-oriented working artwork and templates, not a legal clearance or finished bespoke typeface. Before public launch: perform logo/trademark similarity searches, native Arabic lettering review, visual QA at exact target sizes and on actual platform UI. The 16px mark is an optical simplification, not merely the large mark resized.
