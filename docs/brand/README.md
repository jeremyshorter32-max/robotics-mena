# Robotics MENA · Brand overhaul V2

This is the approved 1A articulated-arm logo **retained exactly in vector geometry**, redesigned with a new palette, typographic direction, bilingual compositions, and visual applications.

## What changed
- Primary: Deep Petroleum `#12212B`, Signal Orange `#D65336`, Editorial Paper `#F7F5EF`.
- Data: Mineral Teal `#166773`, Telemetry Mint `#92D4CB`.
- Primary editorial and bilingual font **29LT Zarid Sans** (commercial licence required), technical metadata **DM Mono**.
- Provided visual SVG renders use installed Inter / Noto Sans Arabic as fallback if Zarid is not available. The actual Zarid glyphs ARE NOT included; they must be properly licensed.
- All new tokens, social sharing, favicon, newsletter and brand guide.
- Open `brand_guide.html` to see designs.

## File use
- `logo_*.svg`: editable text and vector 1A logo; light/dark variants and RTL Arabic layout.
- `symbol_*.svg`: exact 1A vector geometry (re-coloured).
- `favicon_*.svg/png`, `favicon.ico`: optical small-size artwork.
- `og_*.svg/png`: English and Arabic social previews.
- `newsletter_*.svg/png`: mastheads.
- `design_tokens.css`: web-design starting point.
- `brand_guide.html`: responsive design overview, opens locally in browser.

## Production checks
1. Acquire 29LT Zarid Sans and DM Mono rights before live site usage; test the exact licensed faces, and convert approved final wordmarks to outlines before distribution.
2. Have an Arabic typography professional verify Arabic mark alignment and all RTL templates.
3. Validate favicon at actual sizes on browser light/dark favicons.
4. Conduct trademark similarity and category clearance before launch.
5. Document and source real-world photography; never use conceptual visualizations as documentary evidence.

Mockups intentionally avoid fabricated platform statistics.
