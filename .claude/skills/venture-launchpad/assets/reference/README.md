# Reference snapshots (Robotics MENA, 17 Nov 2026)

Real, working files from Robotics MENA, kept here to adapt for a new project. They are **not** project-neutral:
they contain Robotics MENA's name, repository, handles, scope rules, collections and artifact addresses. Read them
for structure and wording, then write the new project's own version. Don't copy one across unchanged.

- `agent-skills/`: the eight agent skills (`SKILL.example.md`) and the report template. See `references/agents.md`.
- `social/`: strategy, voice, account set-up, cadence, Reddit community rules, library page and refresh routine,
  launch campaign plan. See `references/social.md`.
- `scripts/`: social validator and card renderer, content library builder, newsletter (Kit), report PDFs, brief
  archive, the original domain-specific validator and assembler, and `catmon/` (read-only web-filter monitor with
  its workflow and config). `tests/` has matching tests.
- `docs/`: the pre-launch editorial audit, the admin portal plan, the web-filter submission pack.
- `partials/signup-modal.example.html`: the "get the brief" pop-up.

Anything here that conflicts with `references/` is superseded by `references/`.
